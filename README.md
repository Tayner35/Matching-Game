# Matching Game

Small browser-based matching game published with GitHub Pages.

Live site: https://tayner35.github.io/Matching-Game/

## Status

Lightweight demo project. Keep this repo as the canonical matching-game implementation, and avoid duplicating similar one-off matching game repos unless they serve a distinct course or exam.

## Contents

- `index.html` is the main published game.
- `disease-symptom-matching-mobile.html` is a mobile-oriented variant.
- `.nojekyll` keeps GitHub Pages from applying Jekyll processing.
